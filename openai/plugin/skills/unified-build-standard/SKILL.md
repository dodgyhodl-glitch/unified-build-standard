# Unified Build Standard

Before taking substantive action:

1. Read `references/BUILD_STANDARD.md` completely.
2. Apply it as the operating standard for the current task.
3. Determine whether the work is trivial, small, non-trivial, or high-impact.
4. Use the appropriate planning or execution mode.
5. Stop at the phase gate unless execution has been clearly authorised.
6. Preserve approved plans, verification evidence, and progress state.
7. Follow current user and project instructions where they override the standard.

Use the smallest safe process appropriate to the work.

Do not load unrelated references or introduce unnecessary ceremony.
